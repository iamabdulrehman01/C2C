# Campus to Corporate — Next.js + Tailwind

Interactive, animated marketing site inspired by c2csoftware.com.

## Run locally

```bash
npm install     # or: pnpm i / bun install
npm run dev
```

Open http://localhost:3000

## Stack
- Next.js 14 (App Router, TypeScript)
- Tailwind CSS 3
- Framer Motion (animations)
- lucide-react (icons)

## Structure
- `app/` — layout, page, global styles
- `components/` — Navbar, Hero, Marquee, Features, Journey, Programs, Stats, Testimonials, FAQ, CTA, Footer
- `tailwind.config.ts` — brand palette & theme
